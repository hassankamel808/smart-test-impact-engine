# Smart Test Impact Engine

Smart Test Impact Engine is a university research project focused on identifying
and evaluating which tests are most relevant to a given change.

This repository contains the shared project structure for the research team.
The test selection engine itself is not implemented here as part of the initial
repository setup.

## Repository sections

- `m2-execution/` — execution environment, configuration, harness, artifacts,
  and security work for milestone M2.
- `src/test_impact_engine/` — reserved for the implementation of the test impact
  engine.
- `tests/` — reserved for automated tests.
- `contracts/` — shared data contracts, to be added after team members agree on
  their interfaces.
- `experiments/` — experiment workspaces for milestones M3, M4, and M5.
- `research/` — member-specific research notes and findings.
- `decisions/technology-log.md` — record of technology and design decisions.
- `risk-register.md` — shared project risks and mitigations.
